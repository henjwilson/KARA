Running:

1) python3 -m venv venv
2) Start virtual environment: " source venv/bin/activate "
3) Download requirements.txt: " pip install -r requirements.txt "
5) Run: " python3 main.py "

NOTE: cap = cv2.VideoCapture(1) --> 0 is your default webcam; sometimes 1 defaults to 0. You might need to restart the program to get the Logitech camera to show
